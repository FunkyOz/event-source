Event Source examples

Each example shows one feature of funkyoz/event-source. Their code is in the examples/ folder.

Counter

Event ids, resuming with Last-Event-ID, and a final event.

Chat

Messages from a database, sent to every open tab. History on the first connection.

Progress bar

A generator stream that runs a task and reports its progress.

Background job

Follow a job, survive a page reload, and stop reconnecting with 204.

Dashboard

Server metrics, sent only when they change, with heartbeats in between.

Errors

A failing stream: error listeners, stop reasons and reconnection.
